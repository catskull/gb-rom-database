# gb-rom-database

[View the database at catskull.net/gb-rom-database](https://catskull.net/gb-rom-database/)

## Development

```bash
git clone https://github.com/catskull/gb-rom-database.git
cd gb-rom-database
python3 -m http.server
```

App should be running at [http://localhost:8000](http://localhost:8000)

## Contributing

Submit a PR. Mostly looking for data cleanup, acessibility improvments, and bug fixes.
